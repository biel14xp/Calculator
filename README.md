# 🧮 Calculator

A responsive, interactive web calculator with real-time error handling. This project was developed to consolidate fundamental front-end development concepts (HTML, CSS, and JavaScript), as well as practice version control with Git and deployment via deployment via GitHub Pages.

---

## 🚀 Features

- **Basic Operations:** Addition, subtraction, multiplication, division, and percentage calculation.
- **Intelligent Interface (Grid):** Clean, modern layout, fully aligned using CSS Grid and Flexbox.
- **Error Handling:** System protected with `try...catch` that prevents code processing and displays a friendly "Error" message if the mathematical expression is invalid.
- **Backspace Control (⌫):** Allows deleting the last typed character without losing the entire current count.
- **Visual Effects:** Visual feedback with `:hover` on buttons, highlighting colors for operators.
