# 🧮 Modern Web Calculator

A responsive, interactive web calculator with real-time error handling. This project was developed to consolidate fundamental front-end development concepts (HTML5, CSS3, and JavaScript ES6+), as well as practice version control with Git and deployment via GitHub Pages.

> 🌐 **Access the live project here:** [Link to your GitHub Pages](https://biel14xp.github.io/Calculator/) *(Replace with your actual link)*

---

## 🚀 Features

- **Basic Operations:** Addition, subtraction, multiplication, division, and percentage calculation.

- **Intelligent Interface (Grid):** Clean, modern layout, fully aligned using CSS Grid and Flexbox.

- **Error Handling:** System protected with `try...catch` that prevents code processing and displays a friendly "Error" message if the mathematical expression is invalid.

- **Backspace Control (⌫):** Allows deleting the last typed character without losing the entire current count.

- **Visual Effects:** Visual feedback with `:hover` on buttons, highlighting cores for operators.

---

## 🛠️ Technologies Used

* **HTML5:** Semantic and accessible layout structuring.

* **CSS:** Modern styling, use of core variables, Flexbox for centering, and CSS Grid for button arrangement.

* **JavaScript:** DOM event handling, dynamic functions, and execution logic with `eval()`.
